Connecting Your Broker

Charticks 0.1.0 · Adding an account and getting live prices

The app ships with no accounts. An empty Brokers screen on first launch is correct, not a fault. Every user enters their own credentials, and they are encrypted on your machine using Windows' own protection — they never leave it except to log in to your broker.

Step 1 — Add your account

  1. Open the Brokers screen from the left rail.
  2. Click Add Broker.
  3. Choose your broker and give the account a nickname (anything you like).
  4. Fill in the credentials — see the table below for what each broker needs.
  5. Click Save, then select the account and click Connect.

The status dot should turn green.

StatusMeaning
GreenConnected and streaming.
AmberConnecting, or the session expired and needs a re-login.
RedLogin failed. Check the credentials.

What each broker needs

BrokerFields
Angel One API Key, Client ID, PIN, TOTP Secret
Kotak Neo Consumer Key, Mobile No. (+91…), UCC, MPIN, TOTP Secret
Dhan HQ Client ID, Access Token
ICICI Direct API Key, API Secret — then use the Log in with ICICI button. The session key is issued by a browser login and expires daily, so this one needs redoing each morning.

The TOTP Secret is the long text string your broker showed you when you enabled two-factor authentication — not the 6-digit code. The app generates the 6-digit code itself at each login.

Angel One — whitelist your IP first

This step is not optional. Angel rejects every order from an unregistered IP address with:

AG7002 — "<your ip> is not a registered IP, please check your registered IP."

Market data still works, so everything looks fine until your first order fails.

  1. Find your public IP — search “what is my IP” in a browser.
  2. Log in to the Angel SmartAPI dashboard where you created your API app.
  3. Add that IP to the app's whitelist and save.
  4. Reconnect the account in Charticks.

If your IP changes, orders stop working. Mobile hotspots, 4G/5G dongles and some home broadband (CGNAT) hand out a different IP regularly — sometimes daily. If orders suddenly start failing, re-check your IP before assuming the app broke.

A fixed/static connection is strongly preferred for live trading.

Step 2 — Check you are getting data

With a green dot you should see:

  • Index tiles (NIFTY, BANKNIFTY…) showing prices that change
  • The Option Chain listing strikes with Call and Put prices

If prices appear but never move, the market is probably closed. Indian equity derivatives trade 09:15 – 15:30 IST, Monday to Friday. The app has no holiday calendar, so on a trading holiday it will look open but nothing will move.

Changing credentials later

Select the account → Manage → Edit Credentials. You can also Rename or Delete an account from the same menu.

After editing credentials, disconnect and reconnect the account. The running engine keeps using the old credentials until you do — so a corrected PIN or TOTP secret will appear to save successfully and change nothing.

Keeping your credentials safe

  • Secrets are masked in the UI and encrypted at rest at %APPDATA%\charticks\brokers.json.
  • Never share a screenshot showing credentials. Crop or blur them first.
  • Use a test account with limited funds while evaluating this build.
  • If you ever suspect a key was exposed, rotate it at your broker immediately.

Before placing a live order, read KNOWN-LIMITATIONS.html. You can open and close live positions from the app, but Stop Loss and Target do not act on them — nothing exits automatically.
