Charticks — Install Guide

Execution Terminal, version 0.1.0 · Windows 10 / 11

Nothing else needs installing. Earlier versions of this app asked you to install Python and run a setup script. That is no longer true — the trading engine is built into the installer. If you were sent a setup-tester.bat file, ignore it.

What you need

  • A Windows 10 or 11 PC
  • An internet connection
  • About 1 GB of free disk space
  • A broker account (Angel One) if you want live market data — see BROKER-SETUP.html

Step 1 — Run the installer

  1. Double-click Charticks Setup 0.1.0.exe.

Expected“Windows protected your PC”

A blue box will appear saying Windows does not recognise the app. This is normal — the build is not code-signed yet, so Windows has no publisher to check against.

Click More info, then Run anyway.

  1. That is it.

There is no wizard, no options to choose and no folder to pick. The installer runs, finishes in a few seconds, and opens the app automatically. It also adds a Charticks shortcut to your Desktop and Start Menu.

Step 2 — First launch

Give it up to 10 seconds the first time. The trading engine starts in the background, and Windows may scan the new files on first run.

You should see the main window with index tiles (NIFTY, BANKNIFTY and so on) and an option chain area. Both will be empty until you connect a broker.

An empty Brokers screen is correct. The app ships with no accounts and no credentials. You enter your own — see BROKER-SETUP.html.

Where things are installed

WhatWhere
The application %LOCALAPPDATA%\Programs\charticks
Your broker credentials
encrypted by Windows		 %APPDATA%\charticks\brokers.json
Log files
send these if you report a problem — or use Settings → Diagnostics inside the app		 Documents\Charticks\logs

Paste either path into the File Explorer address bar to open it. The install is per user — it does not need administrator rights and does not touch Program Files.

Verifying the download (optional)

To confirm the installer arrived intact, open PowerShell in this folder and run:

Get-FileHash ".\Charticks Setup 0.1.0.exe" -Algorithm SHA256

Compare the result with the value in SHA256SUMS.txt. They must match exactly.

Uninstalling

Windows Settings → Apps → Installed apps → Charticks → Uninstall.

That removes the application but leaves your saved broker accounts and logs in %APPDATA%\charticks. Delete that folder by hand if you want a completely clean removal.
